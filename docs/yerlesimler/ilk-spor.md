# İlk Spor

+Derin Hafıza Çemberlerinin en eski Myconid merkezidir. Sokak yerine paylaşılan hafıza bölgeleri vardır.

Kara Hasat'ın anılarının ortak ağa kabul edilip edilmeyeceği çemberleri bölmektedir.
