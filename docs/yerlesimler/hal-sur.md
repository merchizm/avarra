# Hal-Sur

<p class="lore-lead">Kurumuş iç denizin altındaki beyaz tuz galerilerine kurulmuştur. Maden hissesi sahibi aileler oy kullanır; Goblin ve Kobold çoğunluk yurttaş değildir.</p>
