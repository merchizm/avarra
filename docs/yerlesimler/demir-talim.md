# Demir Talim

+Külordu Marklığı'nın bütünüyle askerî eğitim çevresinde gelişmiş başkentidir. Sokaklar tatbikat alanı, meydanlar lojistik deposu olarak kullanılabilir.

Üç Ordan adayı da Külordu askerlerini kiralamıştır. Aynı okuldan mezun birliklerin farklı cephelerde karşılaşma ihtimali askerî meclisi bölmektedir.
