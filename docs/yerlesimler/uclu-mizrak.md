# Üçlü Mızrak

+Triton Derin Nöbeti'nin ana kalesidir. Üç deniz çukurunun kesişimindeki dev sütunlar üzerine kuruludur.

Nöbet, yüzeye açıklamadığı bir canavar göçü nedeniyle bütün filolarını toplamaktadır.
