# Velis

+Sis Adaları'nın maskeli başkentidir. Bir yurttaşın birden fazla yasal yüzü olabilir. Senato üyeleri oturum sırasında kişisel kimliklerini gizler.

**Mahalleler:** Maskeli Senato, Sigorta Rıhtımı, Kızıl Fener, Yüzsüz Avlu, Dokuzuncu Masa çevresi.  
**Güncel kriz:** Aynı kişinin iki kimliği farklı Ordan taht adaylarıyla çelişen antlaşmalar imzalamıştır.
