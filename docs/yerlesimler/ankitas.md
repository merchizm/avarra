# Yankıtaş

+Camova Konfederasyonu'nun SS 83 meclis merkezidir. Kristal arşivler, tarafsız toplantı salonları ve element ocaklarının elçilikleri bulunur.

Şehirde konuşmalar kristallere kaydedilir; fakat hangi kaydın kamusal olacağı ayrı hukuk konusudur. Ordan yanlıları yol antlaşması, bağımsızlıkçılar maden sayımının yasaklanmasını ister.
