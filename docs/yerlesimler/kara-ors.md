# Kara Örs

+Büyük magma odasına zincirlerle asılı Duergar monarşi başkentidir. Yüksekteki zincir saraylar soylulara, sıcak alt platformlar işçilere ayrılmıştır.

Kor-Dum'dan kaçan soylular ve Kara Örs'ten kaçan işçiler iki devlet arasında sürekli casusluk yaratır.
