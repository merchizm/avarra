Silent Hollow is built to appear as an absence on a map. It is found where incoming vibration vanishes, which protects it from invasion but makes calling for aid in a water or lantern failure difficult. **Dim Halls** decide citizenship in sign language; **Neutral Tunnel** is its only exchange with outsiders.

### Table tensions

- An unmarked chest left in the tunnel grows warmer each day.
- Sound-eating stones ring once at night: someone inside has spoken.
- A Last Glow ballot carries a light colour Silent Hollow never uses.
