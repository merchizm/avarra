# Doctrine of the Soul and Death
 <p class="lore-lead"> The widely accepted language on Spirit uses three elements: Breath, Name, and Trace. </p>
 <div class="lore-grid"> <div class="lore-card"> <h3> Breath </h3> <p> The power that provides vitality; It mixes with the environment after death, it is not a personality alone. </p> </div> <div class="lore-card"> <h3> Name </h3> <p> Will, memory and self; the holistic identity that must be invoked in true resurrection. </p> </div> <div class="lore-card"> <h3> Trace </h3> <p> Emotional and magical residue. Not every ghost is a real spirit. </p> </div> <a class="lore-card" href="./esik-araligi"> <h3> Threshold Range </h3> <p> The state of the soul that cannot complete its transition. </p> </a> <a class="lore-card" href="./diriltme-ayinleri"> <h3> Rites of resurrection </h3> <p> Memory, Three Bonds, Open Door, and Return from the Name. </p> </a> </div>
