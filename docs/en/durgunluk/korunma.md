# Recession Protection
 <p class="lore-lead"> No absolute protection. Border guards carry their name and the last three days written on them; The magic clock uses running water and sprouting seeds. </p>
 <ul> <li> Compare memory with teammates regularly. </li> <li> Do not travel alone; Do not open an unmarked ancient door. </li> <li> Return to a repeated sound, path, or conversation. </li> <li> If animals stop, the path repeats and the wound does not heal, leave the area. </li> </ul>
