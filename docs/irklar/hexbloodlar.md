# Hexbloodlar

<p class="lore-lead">Fey, kadim büyü veya cadı anlaşmalarıyla hayatı değişmiş; kökenleri kadar seçimleriyle de tanımlanan kişiler.</p>

## Kanonik kayıt

<p>Hexbloodlar cadı, Fey veya yaşayan orman antlaşmaları sonucunda dönüşmüş kişilerdir. Diken Tacı'nda Solgun Çember tarafından korunabilir; Ordan'da kayıt dışı büyü taşıyıcısı sayılır.</p>
<p>Bir Hexblood eski kültürünü kaybetmez. Dönüşümden sonra aile bağlarının sürüp sürmeyeceği toplumun hukukuna bağlıdır. Bazıları kendi küçük antlaşma ailelerini kurar.</p>
